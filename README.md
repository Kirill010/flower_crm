## 📌 О программе

**Muzflowers CRM** — это профессиональная система управления цветочным бизнесом, разработанная специально для цветочных магазинов. Она объединяет две ключевые функции:

### 🛍️ Розничная торговля
- Приём заказов от частных клиентов
- Учёт товаров, расходов, клиентов
- Управление складом и поставщиками

### 🏢 B2B-сервис корпоративных поздравлений
- Автоматизация поздравлений сотрудников компаний
- Доставка цветов и подарков на дни рождения и праздники
- Выставление счетов и контроль оплат

**Программа автоматически:**
- Следит за днями рождения сотрудников ваших корпоративных клиентов
- Каждое утро в 8:00 создаёт заказы на завтрашние дни рождения
- Позволяет одним нажатием создать заказы для всех сотрудников на любой праздник
- Добавляет к заказу открытки, сладости или оформление офиса
- Выставляет счета корпоративным клиентам и контролирует оплаты

**Это не просто учёт — это готовый инструмент для превращения вашего магазина в сервис корпоративных поздравлений по подписке.**

## ⚙️ Установка и запуск

### Системные требования:
- **Python** 3.8 или новее
- **Операционная система:** Windows, Linux, macOS
- **ОЗУ:** минимум 2 ГБ
- **Место на диске:** ~100 МБ

### Шаг 1: Установите Python

Если Python не установлен, скачайте его с [python.org](https://www.python.org/downloads/).

**Для Windows:**
- Скачайте установщик
- Запустите его
- ✅ Обязательно отметьте "Add Python to PATH"

**Для macOS:**
```bash
brew install python
```

**Для Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install python3 python3-pip
```

### Шаг 2: Установите зависимости

Откройте командную строку (терминал) и выполните:

```bash
pip install PyQt5 sqlalchemy openpyxl matplotlib werkzeug apscheduler
```

**Или используйте файл `requirements.txt`:**

```bash
pip install -r requirements.txt
```

### Шаг 3: Скачайте программу

Скачайте файл **`crm.py`** (рекомендуемая версия) в любую папку.

### Шаг 4: Запустите программу

```bash
python crm.py
```

**Примечание:** Рекомендуется использовать `crm.py`, так как он содержит исправления критических багов.

## 📂 Подробное описание вкладок

### 🏠 Главная (Dashboard)

**Цель:** получить общую картину бизнеса и быстро перейти к основным действиям.

#### Блоки:

**1. Метрики (7 цветных карточек):**

| Метрика | Описание |
|---------|----------|
| 💰 **Выручка (мес)** | Выручка за текущий месяц (только доставленные заказы) |
| 📈 **Прибыль (мес)** | Прибыль за месяц (выручка – себестоимость – расходы) |
| 📦 **Всего заказов** | Общее количество заказов (все) |
| 👤 **Клиентов** | Количество клиентов (физ. лиц) |
| 🏢 **Корп. клиентов** | Количество корпоративных клиентов |
| ⚠️ **Заканчивается** | Количество позиций на складе с остатком ниже минимального |
| 💸 **Дебиторка (корп)** | Общая сумма просроченной дебиторской задолженности (корп. клиенты) |

**2. Заказы на завтра**

Таблица со всеми заказами, запланированными на завтра. Помогает ничего не забыть.

**3. Ближайшие события**

Список праздников и дней рождения сотрудников корп. клиентов на ближайшие 30 дней, с указанием количества дней до события.

**4. Быстрые действия**

Кнопки для частых операций:
- ➕ **Новый заказ (Ctrl+N)** — создать новый заказ
- 📤 **Экспорт (Ctrl+E)** — экспортировать заказы в Excel
- 📥 **Импорт** — импортировать заказы из Excel
- 💾 **Бэкап** — создать резервную копию
- 🤖 **Автозаказы** — запустить автозаказы вручную

### 🛍️ Заказы

**Цель:** управление всеми заказами – розничными и корпоративными.

#### Фильтры:

| Фильтр | Описание |
|--------|----------|
| **Статус** | новый, принят, собирается, готов, доставлен, отменён |
| **Повод** | День рождения, 8 Марта, Новый год и др. |
| **Поиск** | По номеру заказа, клиенту, букету, адресу, комментарию |

#### Таблица заказов содержит:

- Номер заказа
- Дата доставки
- Время доставки
- Клиент
- Получатель
- Повод
- Букет
- Количество
- Сумма
- Статус
- Оплата
- Отметки об открытке, сладостях, оформлении офиса

#### Действия:

| Действие | Описание |
|----------|----------|
| ➕ **Новый заказ (Ctrl+N)** | Открывается форма создания заказа |
| ✏️ **Редактировать** | Редактирование выбранного заказа |
| 🗑️ **Удалить** | Удаление заказа |
| 🔄 **Обновить** | Обновление списка заказов |
| 📤 **Excel** | Экспорт всех заказов в Excel-файл |
| 📥 **Импорт** | Загрузка заказов из Excel |

**Двойной клик** по строке — редактирование заказа.

#### Форма заказа:

**1. Выбор клиента:**
- **Клиент (физ. лицо)** — выберите из списка или создайте нового
- **Корпоративный клиент** — выберите компанию

**2. Основная информация:**
- **Повод** — День рождения, 8 Марта, Новый год и др.
- **Дата заказа** — когда создан заказ
- **Дата доставки** — когда доставить
- **Время доставки** — во сколько доставить

**3. Товар:**
- **Из каталога** — выберите товар из каталога (автоматически заполнятся название, состав, цена)
- **Букет** — название букета
- **Состав** — из чего состоит букет
- **Количество** — сколько букетов

**4. Финансы:**
- **Сумма продажи** — цена для клиента
- **Себестоимость** — сколько вам обошлось

**5. Доставка:**
- **Получатель** — кому доставить
- **Телефон получателя** — для связи
- **Адрес доставки** — куда доставить

**6. Статус и ответственные:**
- **Статус** — новый, принят, собирается, готов, доставлен, отменён
- **Флорист** — кто собирает букет
- **Оплачен** — отметка об оплате

**7. Дополнительные услуги:**
- 📨 **Открытка (+100 ₽)** — добавить открытку
- 🍬 **Сладости (+200 ₽)** — добавить сладости
- 🌿 **Оформление офиса** — оформление офиса

**8. Комментарий** — для внутренних пометок

> **Особенность:** если выбран корпоративный клиент, поле «Клиент (физ. лицо)» автоматически заполняется фиктивным клиентом с именем `[Название компании]` – это сделано для унификации структуры заказов.

## ❓ Часто задаваемые вопросы (FAQ)

**1. Можно ли добавить нового пользователя?**

Да, только администратор через меню "Настройки → Пользователи системы".

**2. Как изменить пароль?**

Каждый пользователь может изменить свой пароль через меню "Профиль → Сменить пароль". Администратор может сбросить пароль любому пользователю в разделе управления пользователями.

**3. Что делать, если я забыл пароль администратора?**

Удалите файл `muzflowers.db` – при следующем запуске создадутся тестовые учётные записи (все данные будут потеряны). Либо используйте SQLite-браузер, чтобы изменить хеш пароля вручную (не рекомендуется).

**4. Можно ли использовать программу без корпоративных клиентов?**

Да, вы можете вести только розничную торговлю, игнорируя вкладки B2B, Счета, Праздники. Программа работает как обычная CRM для цветочного магазина.

**5. Как добавить новую услугу (например, шарики)?**

В модели `Order` добавьте поле, в диалоге заказа – чекбокс, в экспорте/импорте – колонку. Код открыт, вы можете его доработать.

**6. Поддерживает ли программа несколько магазинов?**

Да, база данных спроектирована с учётом нескольких магазинов (поле `store_id` во многих таблицах). Однако интерфейс текущей версии работает только с одним активным магазином (первым в таблице `stores`). Для работы с несколькими магазинами потребуется небольшая доработка (например, выбор магазина при входе).

**7. Какие операционные системы поддерживаются?**

Windows, Linux, macOS – везде, где работает Python и PyQt5.

**8. Как обновить программу до новой версии?**

Просто замените файл `crm.py` на новую версию. База данных останется нетронутой. Если в новой версии изменилась структура БД, программа автоматически применит миграции при запуске (используется `Base.metadata.create_all`).

**9. Можно ли изменить время автоматических задач?**

Да, в методе `setup_scheduler()` главного окна измените параметры `trigger='cron'` (час, минута). Например, для автозаказов измените строку:
```python
self.scheduler.add_job(func=self.run_auto_orders, trigger='cron', hour=8, minute=0, id='auto_orders_daily')
```

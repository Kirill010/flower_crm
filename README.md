# flower_crm

# 🌹 Muzflowers CRM — полное руководство по системе

---

## 📌 О чём эта программа

Это **CRM-система**, созданная специально для цветочного бизнеса. Она решает две задачи:

1. **Розничная торговля** – приём заказов от частных клиентов, учёт товаров, расходов, клиентов.
2. **B2B-сервис корпоративных поздравлений** – автоматизация поздравлений сотрудников компаний (дни рождения, праздники) с доставкой цветов и подарков.

Программа **автоматически**:
- следит за днями рождения сотрудников ваших корпоративных клиентов,
- каждое утро в 8:00 создаёт заказы на завтрашние дни рождения,
- позволяет одним нажатием создать заказы для всех сотрудников на любой праздник (8 Марта, Новый год и т.д.),
- добавляет к заказу открытки, сладости или оформление офиса,
- выставляет счета корпоративным клиентам и контролирует оплаты.

**Это не просто учёт – это готовый инструмент для превращения вашего магазина в сервис корпоративных поздравлений по подписке.**

## ⚙️ Установка и запуск

1. Установите **Python 3.8** или новее (если не установлен – скачайте с python.org).
2. Откройте командную строку (терминал) и установите необходимые библиотеки:
   ```bash
   pip install PyQt5 sqlalchemy openpyxl matplotlib werkzeug apscheduler
   ```
3. Скачайте файл `crm.py` (или `muzflowers.py`) в любую папку.
4. Запустите программу:
   ```bash
   python crm.py
   ```
   > При первом запуске автоматически создадутся база данных `muzflowers.db`, тестовый магазин, пользователи и праздники. Никаких дополнительных настроек не нужно.

## 🔑 Вход в систему

После запуска появится окно входа. Используйте одну из учётных записей:

| Логин     | Пароль    | Роль         | Описание |
|-----------|-----------|--------------|----------|
| `admin`   | `admin123`| **Администратор** | Полный доступ: управление пользователями, все данные, настройки. |
| `manager` | `manager123` | **Менеджер** | Работа с заказами, клиентами, корп. клиентами, счетами, статистикой. Без управления пользователями. |
| `florist` | `florist123` | **Флорист** | Просмотр заказов, изменение статуса (собирается, готов). Не может создавать/удалять заказы. |

> **Совет:** сразу после входа смените пароль администратора в меню **Настройки → Пользователи системы**.

## 📂 Подробное описание вкладок (энциклопедия)

### 🏠 Главная (Dashboard)
**Цель:** получить общую картину бизнеса и быстро перейти к основным действиям.

**Блоки:**
1. **Метрики** (7 цветных карточек):
   - Выручка за текущий месяц (только доставленные заказы)
   - Прибыль за месяц (выручка – себестоимость – расходы)
   - Общее количество заказов (все)
   - Количество клиентов (физ. лиц)
   - Количество корпоративных клиентов
   - Количество позиций на складе с остатком ниже минимального
   - Общая сумма просроченной дебиторской задолженности (корп. клиенты)
2. **Заказы на завтра** – таблица со всеми заказами, запланированными на завтра. Помогает ничего не забыть.
3. **Ближайшие события** – список праздников и дней рождения сотрудников корп. клиентов на ближайшие 30 дней, с указанием количества дней до события.
4. **Быстрые действия** – кнопки для частых операций:
   - Новый заказ (Ctrl+N)
   - Экспорт заказов в Excel (Ctrl+E)
   - Импорт заказов из Excel
   - Создать резервную копию
   - Запустить автозаказы вручную

### 🛍️ Заказы
**Цель:** управление всеми заказами – розничными и корпоративными.

**Фильтры:**
- По статусу (новый, принят, собирается, готов, доставлен, отменён)
- По поводу (День рождения, 8 Марта, Новый год и др.)
- Поиск по номеру заказа, клиенту, букету, адресу, комментарию

**Таблица заказов** содержит: номер, дата доставки, время, клиент, получатель, повод, букет, количество, сумма, статус, оплата, отметки об открытке, сладостях, оформлении офиса.

**Действия:**
- `➕ Новый заказ (Ctrl+N)` – открывается форма создания заказа.
- Двойной клик по строке – редактирование заказа.
- `🗑️ Удалить` – удаление заказа.
- `📤 Excel` – экспорт всех заказов в Excel-файл.
- `📥 Импорт` – загрузка заказов из Excel (формат должен совпадать с экспортным шаблоном).

**Форма заказа:**
- Выбор клиента (физ. лицо) или корпоративного клиента.
- Если выбран корпоративный клиент, автоматически подставляется его фиксированная цена или бюджет сотрудника.
- Можно выбрать товар из каталога – тогда подтягиваются название, состав, цена.
- Вручную заполнить букет, состав, количество, сумму, себестоимость.
- Указать получателя, телефон, адрес доставки.
- Выбрать статус, назначить флориста.
- Отметить оплату, добавить открытку (+100 ₽), сладости (+200 ₽), оформление офиса – сумма пересчитывается автоматически.
- Комментарий для внутренних пометок.

### 🏢 B2B (Корпоративные клиенты)
**Самый важный раздел.** Именно здесь настраивается сервис корпоративных поздравлений.

**Верхняя таблица – Компании-клиенты:**
- ID, название компании, контактное лицо, телефон, скидка, дата окончания договора, количество сотрудников, сумма долга.
- Кнопки: «Добавить компанию», «Редактировать», «Удалить», «Экспорт КП» (создаёт коммерческое предложение в Excel).

**Форма компании:**
- Название, контактное лицо, телефон, адрес.
- № и даты договора, срок действия.
- Скидка (в процентах).
- **Фиксированная цена букета** – эта цена будет использоваться для автозаказов, если у сотрудника не указан свой бюджет.
- Условия оплаты (например, «По счёту раз в месяц»).
- Персональный менеджер (выбирается из сотрудников магазина с ролью `manager`).
- Заметки.

**Нижняя таблица – Сотрудники компании:**
- ID, ФИО, должность, день рождения, телефон, предпочитаемый букет, бюджет.
- Кнопки «Добавить сотрудника», «Редактировать», «Удалить».
- **При выборе компании в верхней таблице, в нижней отображаются её сотрудники.**

**Как это работает для бизнеса:**
1. Вы добавляете компанию.
2. Добавляете всех её сотрудников, указывая их дни рождения и предпочтения.
3. Программа автоматически (в 8:00) создаёт заказы на день рождения каждого сотрудника за день до события.
4. Сумма заказа берётся из бюджета сотрудника, если он указан, или из фиксированной цены компании.
5. Вы получаете стабильный поток заказов, а клиент – готовое решение без лишних хлопот.

### 🎉 Праздники и массовые заказы
**Цель:** подготовка к массовым праздникам (8 Марта, Новый год и т.д.).

- Таблица праздников: ID, название, дата (день и месяц), дней подготовки, заметки.
- Кнопки «Добавить праздник», «Редактировать», «Удалить».
- **Кнопка «Создать массовые заказы»** – открывается диалог:
  1. Выберите праздник.
  2. Укажите год.
  3. Введите название букета (или оставьте «Праздничный букет»).
  4. Укажите сумму (0 – использовать фиксированную цену компании).
  5. Выберите получателей: все сотрудники, только женщины (для 8 Марта) или только мужчины (для 23 Февраля).
  6. Нажмите «Создать заказы» – программа создаст заказы для всех активных сотрудников всех корпоративных клиентов на выбранную дату.

### 📊 Статистика (Аналитика)
**Цель:** визуализация ключевых показателей.

- **График 1:** динамика выручки, прибыли, расходов и корпоративного дохода за последние 6 месяцев.
- **График 2:** распределение заказов по статусам (круговая диаграмма).
- **ABC-анализ товаров:** таблица, где товары отсортированы по доле прибыли. Класс A – приносят 80% прибыли, класс B – следующие 15%, класс C – остальные 5%. Помогает понять, на чём зарабатываете больше всего.
- Кнопка «Обновить графики» для пересчёта.

## 🧑‍💼 Пошаговые сценарии для разных ролей

### Для Администратора (первый запуск)
1. Войти под `admin/admin123`.
2. **Сменить пароль** в меню «Настройки → Пользователи системы».
3. **Добавить менеджеров и флористов** (если нужно) через тот же раздел.
4. **Проверить магазин** – название, адрес, телефон (хранятся в базе, можно изменить через SQLite-бразуер).
5. **Настроить праздники** (по умолчанию уже созданы основные).
6. **Сделать резервную копию** – меню «Файл» → «Создать резервную копию».

### Для Менеджера (ежедневная работа)
1. Войти под `manager/manager123`.
2. **Посмотреть напоминания** – при старте покажутся праздники и предстоящие ДР.
3. **На главной** проверить метрики и заказы на завтра.
4. **Добавить корпоративного клиента**:
   - Вкладка B2B → «Добавить компанию».
   - Заполнить данные, указать фиксированную цену и менеджера.
   - Добавить сотрудников компании (кнопка «Добавить сотрудника»).
5. **Работа с заказами**:
   - Создавать розничные заказы (Ctrl+N).
   - Редактировать статусы, назначать флористов.
   - Отмечать оплату.
6. **Выставлять счета** корп. клиентам (вкладка «Счета»).
7. **Следить за просрочками** – напоминания и индикатор дебиторской задолженности.
8. **Экспортировать заказы** в Excel для отчётности.

### Для Флориста
1. Войти под `florist/florist123`.
2. Вкладка «Заказы» – видеть все заказы.
3. Отфильтровать по статусу «новый» или «принят».
4. Двойным кликом открыть заказ, изменить статус на «собирается» или «готов», назначить себя.
5. **Не может** создавать или удалять заказы, управлять клиентами и финансами.

## ❓ Часто задаваемые вопросы

**1. Можно ли добавить нового пользователя?**  
Да, только администратор через меню «Настройки → Пользователи системы».

**2. Как изменить пароль?**  
Администратор может изменить пароль любого пользователя в том же разделе (создать нового или отредактировать существующего). Сами пользователи не могут менять пароль – это делает админ.

**3. Что делать, если я забыл пароль администратора?**  
Удалите файл `muzflowers.db` – при следующем запуске создадутся тестовые учётные записи (все данные будут потеряны). Либо используйте SQLite-бразуер, чтобы изменить хеш пароля вручную (не рекомендуется).

**4. Можно ли использовать программу без корпоративных клиентов?**  
Да, вы можете вести только розничную торговлю, игнорируя вкладки B2B, Счета, Праздники. Программа работает как обычная CRM для цветочного магазина.

**5. Как добавить новую услугу (например, шарики)?**  
В модели `Order` добавьте поле, в диалоге заказа – чекбокс, в экспорте/импорте – колонку. Код открыт, вы можете его доработать.

**6. Поддерживает ли программа несколько магазинов?**  
Да, база данных спроектирована с учётом нескольких магазинов (поле `store_id` во многих таблицах). Однако интерфейс текущей версии работает только с одним активным магазином (первым в таблице `stores`). Для работы с несколькими магазинами потребуется небольшая доработка (например, выбор магазина при входе).

**7. Какие операционные системы поддерживаются?**  
Windows, Linux, macOS – везде, где работает Python и PyQt5.

## 🛠️ Для разработчиков (кратко)

- **Язык:** Python 3.8+
- **Библиотеки:** PyQt5, SQLAlchemy, openpyxl, matplotlib, werkzeug, apscheduler.
- **База данных:** SQLite (файл `muzflowers.db`).
- **Архитектура:** MVC-подход: модели (SQLAlchemy), представления (PyQt5), контроллеры (в главном окне и диалогах).

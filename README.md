# CRM корпоративных поздравлений

Программа для сервиса из ТЗ «Корпоративное обслуживание компаний по доставке цветов и подарков»
(файл `ТЗ для CRM.docx` в этой папке): «Диантус» берёт на себя поздравления сотрудников и партнёров
компаний-клиентов — ведёт календарь дат, заранее готовит букеты, доставляет точно в дату и время
и раз в месяц выставляет компании счёт.

Настольное приложение: Python + PyQt5 + SQLAlchemy + SQLite, оформлено в фирменном стиле «Диантус»
(цвета, шрифты и эмблема сайта). Все данные — в файле `flower.db` рядом с программой.

## Запуск

```bash
pip install -r requirements.txt
python crm.py            # рабочая база flower.db
python crm.py --demo     # демо с вымышленными данными (отдельная база demo.db)
```

Или двойным щелчком: `start_crm.bat` / `start_demo.bat`. Для рабочего стола можно сделать ярлык на `pythonw crm.py`
с иконкой `assets/dianthus.ico`. Демо-режим удобен, чтобы осмотреться: рабочие данные он не трогает.

## Как требования ТЗ устроены в программе

| В ТЗ | Где в программе |
|---|---|
| Ведёт календарь дней рождения | «Главная → Календарь поздравлений» на 7/14/30 дней; юбилеи (25, 30, 35… лет) выделены |
| Заранее готовит букеты | Заказы на дни рождения создаются сами за N дней (по умолчанию 3) при запуске и каждые 30 минут. В «Требует внимания» — заказы, которые ещё не взяты в работу |
| Доставка в офис или домой | У получателя «Куда доставлять»: офис (адрес компании) или домой (домашний адрес) |
| Открытки и подарки | Открытка с текстом по шаблону, поле «Подарок», услуга «Подарочный набор» |
| Один раз предоставить список дат | «Компании → Загрузить список (Excel)» + «Шаблон списка». Дальше всё идёт автоматически |
| Услуги: ДР, руководители и партнёры, праздники, оформление офиса, наборы | Категория получателя (сотрудник / руководитель / партнёр); вкладка «Праздники» (8 Марта, 23 Февраля, Новый год, профессиональные — по полу и сегменту); услуги «Оформление офиса» и «Подарочный набор» в заказе |
| Целевая аудитория | Сегмент компании (юристы, бухгалтеры, медцентры, банки, IT, производство) и расстояние в км |
| Персональный менеджер | Поле у компании; попадает в КП |
| Доставка точно в дату и время | Время доставки в заказе; статусы «Новый → Готовится → Готов → В пути → Доставлен»; «Лист доставки…» на день в Excel. День рождения в выходной → доставка в офис в пятницу |
| Фиксированные корпоративные цены | «Цена букета по договору» у компании; личный бюджет у получателя. В заказе виден расчёт цены |
| Оплата раз в месяц по счёту | «Счета → Сформировать счета за месяц»: каждой компании один счёт за доставленные заказы; статусы, просрочка, экспорт в Excel |
| Финансовая модель 10 × 15 × 35 € = 5 250 € | В рублях: 10 × 15 × 3 500 ₽ = 525 000 ₽ в месяц. «Главная»: факт и прогноз против плана; «Отчёты»: по месяцам и компаниям. План — в «Настройках» |
| План привлечения клиентов | Воронка «Лид → КП отправлено → Встреча → Пробное поздравление → Клиент»; журнал контактов с датой следующего шага; КП в Word; заказ с галочкой «Пробное поздравление» (скидка из настроек); даты годового договора ставятся при подписании |
| Ключевое предложение | Текст из ТЗ — в КП (Word) |
| Стабильный доход по подписке | За 30 дней до конца договора — напоминание о продлении; договор истёк — автозаказы останавливаются |

## Рабочий день

1. **Главная.** Смотрите «Требует внимания» (красное — срочно) и календарь: оранжевым выделены события без заказа.
   Кнопка «Создать недостающие заказы» создаёт заказы на выбранный период.
2. **Заказы.** Ведите статусы кнопками «Готов → В пути → Доставлен». Накануне — «Лист доставки…» курьеру.
3. **Праздники.** За неделю до праздника нажмите «Создать заказы на праздник…»: программа покажет, сколько заказов будет создано.
4. **В начале месяца** — «Счета → Сформировать счета за месяц». Оплату отмечайте кнопкой «Отметить оплату».
5. **Новые компании.** Заведите компанию (стадия «Лид»), записывайте контакты и следующие шаги; компания сама переходит по воронке, когда вы отмечаете «КП отправлено», «Визит / встреча», «Договор подписан».

Автозаказы создаются **только для компаний со стадией «Клиент»** и действующим договором. Удалённый вручную автозаказ повторно не появится; если по дню рождения уже есть заказ (даже отменённый), новый не создаётся.

## Допущения, которые стоит проверить

- **Валюта — рубли.** В ТЗ цены в евро (средний заказ 35 €, 5 250 € в месяц); в рублях взято 3 500 ₽ за букет и 525 000 ₽ в месяц —
  как бюджет по умолчанию в прежней версии. Всё меняется в «Настройках» (валюта, цена по умолчанию, план).
  Цены, уже записанные в старой базе (40 и 35 у тестовых компаний), программа не пересчитывает — они теперь читаются как рубли.
- **Скидка на пробное поздравление — 30 %.** В ТЗ процент не указан; меняется в «Настройках».
- **Новый год**: в новой базе день доставки — 28 декабря (как день доставки, а не праздника). Праздники правятся во вкладке «Праздники».
- Профессиональные праздники (День юриста и др.) не заведены. Добавьте во вкладке «Праздники» и укажите сегмент — заказы получат только компании этого сегмента.
- Цена открытки по умолчанию 0; для подарков и оформления офиса цена вводится вручную.

## Фирменный стиль «Диантус»

Оформление взято с сайта (`1-site/app/static/style.css`); цвета совпадают с его переменными, это проверяет `tests/test_theme.py`.

- **Цвета**: кремовый фон `#f5efe4`, оливково-зелёный `#4a6741` (кнопки, выделение), медный `#c97b4a` (события без заказа), бронзовый и розовый — для оттенков и предупреждений.
- **Шрифты**: Montserrat — текст; «Dianthus Display» — заголовки и крупные цифры. Это Playfair Display с сайта: лицензия шрифта (SIL OFL)
  резервирует его имя, поэтому изменённая версия названа иначе. Файлы и тексты лицензий — в `assets/fonts/`.
- **Эмблема «Д»**: шапка окна, иконка программы и панели задач, шапка КП и счёта.
- **Документы**: КП в Word и счета/отчёты в Excel — в тех же цветах. В Word заголовки набраны Georgia, текст — Calibri:
  Montserrat и Playfair есть не на каждом компьютере получателя.
- Знака ₽ в наборах шрифтов сайта нет, он рисуется системным шрифтом.
- Цвета и шрифты собраны в одном месте — `theme.py`. Пересобрать шрифты и картинки из файлов сайта (`app/static` репозитория сайта):
  `python -I -B tools/build_brand_assets.py <папка static сайта>` — нужен Python с fontTools, brotli и Pillow.

## Данные и безопасность

- **Резервные копии**: раз в сутки при запуске и перед обновлением схемы — папка `backups/` (хранится 20 последних), кнопка в «Настройках».
- **Обновление со старой версии**: новые поля добавляются к существующей `flower.db`, ничего не удаляется. Перед первым обновлением программа сама делает копию в `backups/`.
- В базе — ФИО, дни рождения, телефоны, домашние адреса людей: не публикуйте её (в `.gitignore` базы исключены).
- Ошибки пишутся в `crm.log`.

| `demo_data.py` | вымышленные данные для `--demo` |

## Тесты

```bash
pip install pytest
python -m pytest tests
```

Интерфейс проверяется без показа окон (`QT_QPA_PLATFORM=offscreen`). Чтобы сохранить скриншоты:
`QT_QPA_FONTDIR=C:/Windows/Fonts CRM_SHOT_DIR=папка python -m pytest tests/test_ui_smoke.py`.
